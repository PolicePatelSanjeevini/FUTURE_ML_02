
# Support Ticket Classification System

## Project Overview

This project focuses on building an intelligent Support Ticket Classification System using Natural Language Processing (NLP) and Machine Learning. The system automatically analyzes customer support tickets, classifies them into appropriate categories, and helps support teams prioritize and manage requests more efficiently.

## Objective

The goal of this project is to:

* Automatically classify customer support tickets based on their content.
* Identify the category of each ticket.
* Assist support teams in handling tickets more efficiently.
* Improve response time and customer satisfaction.

## Project Workflow

### 1. Data Preprocessing

* Removed missing values
* Converted text to lowercase
* Removed punctuation and special characters
* Removed stopwords

### 2. Feature Extraction

* Applied TF-IDF Vectorization
* Converted ticket text into numerical features

### 3. Model Training

* Trained a machine learning classification model
* Learned patterns from historical support tickets

### 4. Model Evaluation

Performance was evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

### 5. Ticket Prediction

The trained model predicts the most suitable category for incoming support tickets.
